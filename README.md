# Knight's Tour Problem - C++ Implementation
## (Warnsdorff’s Rule Algorithm)

### مشروع مادة البرمجة الهيكلية - C++ Project

### وصف المشروع (Description)
هذا البرنامج يحل مسألة "جولة الحصان" في الشطرنج، حيث يهدف إلى تحريك الحصان ليزور كل خانة في رقعة الشطرنج (8x8) مرة واحدة فقط دون تكرار. تم استخدام خوارزمية **Warnsdorff's Rule** لضمان الوصول للحل بسرعة وكفاءة عالية.

### المميزات (Features)
- استخدام **المفاهيم البرمجية**: (Structs, 2D Arrays, Functions, Control Structures).
- **تفاعلي**: يتيح للمستخدم اختيار نقطة البداية للحصان.
- **خوارزمية ذكية**: يعتمد على تقليل الاحتمالات (Greedy Approach) لضمان الحل السريع.

### كيفية التشغيل (How to Run)
1. قم بتحميل ملف `main.cpp`.
2. استخدم أي مترجم C++ (مثل CodeBlocks أو Visual Studio).
3. قم ببناء وتشغيل المشروع (Build and Run).
4. أدخل إحداثيات البداية (من 0 إلى 7).

### لقطة من المخرجات (Sample Output)
عند اختيار البداية (0,0)، ستظهر الرقعة بالأرقام من 1 إلى 64 توضح مسار الحصان.
