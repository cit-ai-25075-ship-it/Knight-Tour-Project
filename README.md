# Knight's Tour Problem - C++ Implementation
## (Warnsdorff’s Rule Algorithm)

### Structural Programming Course - Final Project

### Description
This program solves the classic "Knight's Tour" chess problem. The goal is to move the knight so that it visits every square on an 8x8 chessboard exactly once. The implementation uses **Warnsdorff’s Rule**, a greedy algorithm that ensures high efficiency and fast solutions.

### Features
- **Core C++ Concepts**: Implements `structs`, `2D arrays`, `functions`, and `control structures` (loops & logic).
- **Interactive**: Allows the user to input the starting position (X, Y) for the knight.
- **Optimized**: Uses an intelligent heuristic to find the path instantly.

### How to Run
1. Download the `main.cpp` file.
2. Open it in any C++ IDE (e.g., CodeBlocks, Visual Studio, or Dev-C++).
3. Compile and Run the project.
4. Enter the starting coordinates (0 to 7) when prompted.

### Sample Output
When choosing (0,0) as a starting point, the program will print the 8x8 board with numbers from 1 to 64, representing the sequence of the knight's moves.
